# Inventory Management Analysis

A beginner-friendly data analytics portfolio project using Python, Pandas, NumPy and Matplotlib.

## Project objective
Analyze inventory value, ageing, ABC classification and stock risk to identify items that may need management attention.

## Files
- `Inventory_Management_Analysis_GitHub.ipynb` — complete analysis notebook
- `sample_inventory_data.xlsx` — synthetic sample data for demonstration

## How to run
1. Download both files into the same folder.
2. Open the notebook in Jupyter Notebook, JupyterLab or Google Colab.
3. Install dependencies if needed: `pip install pandas numpy matplotlib openpyxl`
4. Run all cells from top to bottom.

## Important data note
The included Excel dataset is synthetic. It does not represent any real company, customer, branch or inventory record. Do not publish confidential company data without permission.

## Analysis included
- Data inspection and cleaning
- Missing-value and duplicate checks
- Inventory value validation
- Basic inventory KPIs
- Ageing and category analysis
- ABC classification
- Priority stock identification
- Inventory risk classification
- Charts and business recommendations

## Limitations
Supplier, consumption, service usage and lead-time analysis require separate datasets and are not included in this sample project. Risk thresholds are illustrative and should be validated before operational use.
